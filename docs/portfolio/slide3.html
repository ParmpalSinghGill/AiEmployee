Vendor Independence

Swap the LLM without touching business logic

Every model call routes through one interface. No agent, tool, or workflow imports a vendor SDK — so changing provider is a config edit, and the whole system runs offline for tests and CI.
Why this matters: no vendor lock-in, and pricing stays negotiable — switch to a cheaper model, or self-host entirely, without a rewrite. The mock provider runs the full pipeline with no API keys and no network, so the test suite is fast, free, and deterministic.
